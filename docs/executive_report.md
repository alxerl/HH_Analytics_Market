# Executive report policy

This repository intentionally contains no market conclusions because committed data is synthetic
or absent. A published report must identify its observation period, selected queries and areas,
refresh timestamp, salary coverage, duplicate-publication policy, and all material limitations.

Every conclusion must trace to a `mart` view or a versioned recommendation artifact. Do not infer
hiring growth solely from repeat publications, treat missing salary as zero, or generalize beyond
the observed period. Include the quality report run ID with every released dashboard snapshot.
