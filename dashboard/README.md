# Контракт dashboard

Dashboard работает только с витринами `mart`. На каждой странице показываются дата среза,
время обновления, применённые фильтры и понятное empty state.

## Страницы

| Страница | Источник | Grain | Вопрос |
|---|---|---|---|
| Обзор рынка | `mart.market_daily` | дата × роль × seniority × регион | Каков размер и состав рынка? |
| Навыки | `mart.skill_demand_daily` | дата × роль × seniority × skill | Какие навыки востребованы? |
| Зарплаты | `mart.salary_distribution` | дата × роль × seniority × регион | Какой наблюдаемый диапазон зарплат? |
| Работодатели | `mart.employer_activity` | дата × работодатель × роль | Кто активно нанимает? |
| Matching | `reports/recommendations-<date>.json` | вакансия | Какие вакансии подходят профилю? |

## Общие правила

- считать только representative active vacancies;
- общие фильтры: `as_of_date`, `area_id`, `role`, `seniority`;
- различать «нет наблюдений» и «зарплата недоступна»;
- не делить отфильтрованный numerator на неотфильтрованный denominator;
- обновлять dashboard только после успешной проверки `quality`.

## Сверка

Каждый visual связан с витриной и SQL-запросом сверки. Выводы должны относиться только к
наблюдаемому периоду и правилам из [`docs/executive_report.md`](../docs/executive_report.md).
